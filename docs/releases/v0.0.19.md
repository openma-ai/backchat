# Backchat v0.0.19

## Chat and activity
- Standard ACP context-compaction lifecycle with expandable retained summaries,
  stable in-place updates, and persisted replay. No title matching/AIR identity.
- Empty reasoning chunks no longer create historical thinking entries.
- More consistent steering inputs, annotations, running feedback and shimmer.
- Stable collapse/message DOM and history scroll anchoring; virtualized turn jumps.
- Larger compact image rows and full-size image viewing in composer/transcript.

## Shell and runtime
- Traffic-light/sidebar rail alignment across zoom and clearer navigation ink.
- Separate local disclosure from remote execution-location selection.
- Preserve agent-supplied permission labels and remove redundant header menu.
- Reclaim safe, resumable idle agent processes after 20 minutes.
- Recover crashed renderer UI without restarting the main process or resending
  an active prompt, with bounded retries and a manual recovery fallback.
- Reopened sessions mark orphaned work as interrupted instead of running forever;
  surviving main-process prompts remain active across renderer recovery.
- Structured restartable Codex app-server exits show an interruption notice rather
  than a generic error. Retrying remains explicit to avoid duplicating actions.

## Dependencies
- Uses @openma/common 0.11.1 for standard compaction and shared chat fixes.
- codex-acp 2.2.2 and ACP SDK 1.9.0.
- Electron pinned to 42.11.16, including the upstream layout/selection crash fix
  matching the symbolized 42.5.1 renderer crashes, plus the compromised
  eMudhra certificate mitigation (GHSA-jr5w-w6x2-84p9).

## Known limitations
- Renderer recovery is bounded and does not guarantee against every native crash.
- Structured in-transcript reconnect/retry presentation is not included.
- Custom sidebar sections still have legacy entry points; complete removal is
  not part of this release. Idle-process cleanup does not change quit warnings.
