# Backchat v0.0.20

## Subagent（Claude / DSH）
- 支持 Claude 与 DSH 的 ACP RFD 原生子会话：侧栏可进子会话，主会话样式一致。
- New 页增加 Subagents 入口：先列表再进入；子代理快捷 chip 在消息正文下方。
- 侧栏过窄时 chip 缩成仅图标（保留 aria-label），不再直接隐藏。

## Composer
- slash 命令的 `input.hint` 显示为输入框内 ghost 文案；Tab / 右键填入。
- DSH `userQuestions` elicitation 渲染在 composer 的 ask 槽位。

## Shell / 文档
- Linux / Windows 不再预留 macOS traffic-light 侧栏空白。
- CONTRIBUTING：issue/PR 需按规范附 UI 截图；关联 issue 须写 `Closes`/`Fixes`。
