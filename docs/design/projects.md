# Projects surface

Mode: Operate. Extends the existing Backchat visual system; no brand replacement.

## Direction contract
THESIS: A durable project workspace centered on one ongoing coordinator conversation.
OWN-WORLD: Existing Backchat neutral surfaces, Geist typography, subdued borders and compact controls. Honor both user-selected themes.
STORY: Choose a project, add knowledge and instructions, discuss work, inspect delegated tasks and their actual outcomes.
FIRST VIEWPORT: Project name and description above a flexible conversation column; a 288px knowledge rail on wide windows. Worker and activity tabs share the same reading column. Project list is a quiet searchable two-column collection with one create action.
FORM: Claude Projects public information architecture adapted to the existing Backchat shell; explicit user reference, no random visual-world selection. All visible content derives from persisted user input or SDK facts.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No shipping raster assets are required. Native form and focus semantics are retained; dialogs use the existing accessible primitive. Narrow windows stack the knowledge rail below the main content.
